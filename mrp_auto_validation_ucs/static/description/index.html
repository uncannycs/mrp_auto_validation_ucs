See It In Action

1. Create Draft Manufacturing Order

Create or import Manufacturing Orders in the Draft stage. In this example, a draft MO is created for Finished Product A where the component Raw Material A is currently not available in stock.

2. Launch Auto Process Order from Actions

From the Manufacturing Orders list view (or directly from the MO form view), select one or multiple draft orders, click the Actions menu, and choose Auto Process Order.

3. Safe Handling with "Available Quantity" Mode

When choosing the Available Quantity option, the system verifies component availability. If components are missing in stock, the order is confirmed and reserved safely, remaining in the Confirmed stage without force-producing.

4. Immediate Completion with "Forcefully Done"

Select draft Manufacturing Order(s) where you want to immediately complete the production process, auto-consume components, and finish production without stock blockers.

5. Choose "Forcefully Done" in Wizard

In the Auto Process Order popup wizard, select the Forcefully Done process option and click the Auto Process Order button.

6. Manufacturing Order Automatically Marked as Done

The order is instantly transitioned directly from Draft to Done. Required components are consumed, finished quantities are recorded, and stock ledgers/traceability are automatically updated.

Frequently Asked Questions

Find answers to common questions about the Auto Process Manufacturing Order module.

1. How does the Auto Process Manufacturing Order module work?

It automates the entire manufacturing workflow. Instead of manually confirming draft orders, reserving raw materials, generating lot/serial numbers, completing routing operations, and posting inventory step-by-step, users can execute the entire process in a single click via a dedicated wizard.

2. What is the difference between "Available Quantity" and "Forcefully Done" options?

Available Quantity verifies that all raw materials are fully available and reserved in stock before completing the order; if components are missing, the order remains confirmed without producing. Forcefully Done bypasses stock availability checks, forces consumption, and completes the MO immediately.

3. Can I auto-process multiple Manufacturing Orders at the same time?

Yes. You can select multiple draft Manufacturing Orders from the list/tree view, click the Action menu, choose "Auto Process Order", and batch validate all selected orders in one single execution.

4. What happens if a selected Manufacturing Order is not in the "Draft" stage?

The module performs automated validation. If any selected Manufacturing Order is already confirmed, in progress, or done, a warning prompt is raised specifying the non-draft order names to prevent accidental re-processing.

5. How does the module handle finished products tracked by Lot Numbers?

When processing a lot-tracked finished product without an assigned lot, the module automatically generates and links a new sequence-based lot number before completing the production order.

6. How does the module handle finished products tracked by Unique Serial Numbers?

For single-quantity orders (qty = 1), a unique serial number is auto-generated and assigned. For multi-quantity orders (qty > 1), the system automatically splits the order into individual 1-unit records, assigning distinct serial numbers to each unit and marking all completed.

7. How are tracked raw material components handled during auto-processing?

The module automatically assigns existing lot or serial numbers for tracked components. If unassigned, it generates valid lot/serial records on the component move lines and marks them as picked to ensure full traceability compliance.

8. Are routing work orders and operations completed automatically?

Yes. If the Manufacturing Order is configured with work centers and routing operations, the auto-process wizard automatically executes the finish action for all open work orders, logging timestamps and transitioning their state directly to "Done".

9. Does auto-processing update inventory and warehouse stock balances?

Yes. The module triggers the complete standard inventory posting engine, which deducts consumed raw materials from inventory, adds manufactured goods to stock, and generates all corresponding stock valuation moves.

10. Can I launch the Auto Process wizard from the MO Form view?

Yes. The wizard can be opened both from the Action menu in the list view (for multi-order batch execution) and from the Action menu inside any individual Manufacturing Order form.

11. How does the module handle Bill of Materials (BoMs) with by-products?

All by-products configured on the Bill of Materials are automatically calculated, produced, and posted into finished warehouse stock alongside the primary finished product.

12. What happens if an unexpected error occurs on one order during batch processing?

If an order encounters an issue (such as missing mandatory configuration), the error is captured and displayed in a clear summary notification indicating exactly which order encountered the problem without leaving database inconsistencies.

13. Are Manufacturing Orders generated from Sales Orders (MTO) or Reordering Rules supported?

Yes. Any draft Manufacturing Order created through manual entry, Make-to-Order (MTO) procurement routes, or automated reordering replenishment rules can be processed seamlessly using the wizard.

14. Does the module create unnecessary backorders during auto-processing?

No. Under "Forcefully Done" mode or when full production quantities are fulfilled, the order is marked completely as Done without spawning unwanted backorders.

15. Does the module require complex initial setup before use?

No complex setup is required. Once installed, the "Auto Process Order" action is immediately available in the Action menu for Manufacturing Orders, using your existing Bills of Materials, work centers, and sequences out of the box.
